# پوشش Prototype نسخه اول TradeDesk

تمام داده‌ها ساختگی‌اند. «کار می‌کند» یعنی UI و state محلی مرورگر تغییر می‌کند؛ API، دیتابیس، صدور سند و کنترل دسترسی واقعی وجود ندارد.

| قابلیت | صفحه و مسیر | تعامل فعال | فقط نمایشی / محدودیت |
|---|---|---|---|
| صف روزانه | `#today` ← منو | جست‌وجو و فیلتر مسئول/اولویت/موعد، deep-link | انتظارها از dataset نمونه‌اند |
| میز و ایجاد فرصت | `#opportunities` | فیلتر، list/kanban، wizard پنج‌گام، ذخیره محلی | یک قلم اصلی در wizard؛ سرور ندارد |
| پرونده فرصت | `#opportunity?tab=…` | تب، افزودن طرف/فعالیت/وظیفه/پیشنهاد، اقدام بعدی | سلامت و مراحل از قواعد نمونه‌اند |
| دانش کالا | `#product` | روابط و بازگشت به tab پرونده، پنل دستیار | HS، فنی، کشور و مقررات تأییدنشده‌اند |
| دسته‌بندی | تنظیمات ← `#categories` | درخت، مشخصه‌ها، فرم وابسته به دسته | نمونه سیانید سدیم کاملاً آزمایشی است |
| شرکت و شخص | `#companies` ← `#company` / `#contact` | فیلتر، ارتباط شرکت/شخص/فرصت، ثبت تعامل | بررسی ثبتی واقعی انجام نمی‌شود |
| اسناد | `#documents` | فیلتر، wizard تا preview قابل ویرایش، نسخه پیش‌نویس | approve/issue و فایل واقعی ندارد |
| پیشنهادها | فرصت ← `#quotes` | انتخاب/رد با دلیل و ثبت timeline | تبدیل ارز و رتبه قطعی ندارد |
| حمل و بیمه | `#logistics` | افزودن/حذف/جابجایی leg و drawer استعلام | نرخ، پوشش و فایل‌ها ساختگی‌اند |
| وظایف | `#tasks` | فیلتر و تکمیل؛ تغییر next action | اعلان و تقویم واقعی ندارد |
| گزارش‌ها | `#reports` | انتخاب فیلترهای نمایشی و جداول تفکیک‌شده | dataset ثابت؛ export واقعی ندارد |
| تنظیمات | `#settings` | جابه‌جایی گروه‌ها و matrix مجوز | enforce مجوز و persistence سازمانی ندارد |
| دستیار داخلی | پرونده فرصت و کالا | استفاده/ویرایش/رد/ذخیره خروجی نمونه | AI یا جست‌وجوی بیرونی وصل نیست |
| جست‌وجوی سراسری | نوار بالای تمام صفحه‌ها | نتیجه گروهی و رفتن به رکورد | فقط dataset نمونه را می‌گردد |

## مسیرهای بازبینی انتها به انتها

1. `#today` ← `#opportunity` ← `#product` ← لینک «بازگشت به همان بخش پرونده».
2. پرونده ← ثبت پیشنهاد ← `#quotes` ← ثبت تصمیم ← tab تاریخچه.
3. پرونده ← `#logistics` ← افزودن استعلام حمل و بیمه.
4. پرونده/صف اسناد ← «ساخت پیش‌نویس» ← preview ← ذخیره نسخه در صف.
5. `#tasks` ← تکمیل وظیفه ← پرونده و مشاهده اقدام بعدی.
6. نوار جست‌وجوی بالا ← انتخاب فرصت، کالا، شرکت/شخص یا سند.

## خارج از محدوده

تحقیق اینترنتی، آمار تجارت بیرونی، کشف خودکار فروشنده/خریدار و اتصال تلگرام/واتساپ عمداً صفحه و CTA ندارند. این قابلیت‌ها بدون سیاست منبع، رضایت، امنیت ارتباط و backend قابل ارزیابی مسئولانه نیستند و در نسخه اول تعریف نشده‌اند.
