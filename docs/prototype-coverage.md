## معیارهای پیمایش

- منوی اصلی فقط فهرست را باز می‌کند.
- ستون اول هر ردیف به detail همان شناسه می‌رود.
- breadcrumb و «بازگشت به فهرست» از detail به collection برمی‌گردند.
- تمام رابطه‌های مدل‌شده لینک شناسه‌محور دارند؛ بخش بدون داده empty state صریح دارد.
- search، وضعیت و sort در صفحه فهرست روی dataset همان صفحه اثر می‌گذارند.

## خارج از محدوده

تحقیق اینترنتی، کشف خودکار طرف تجاری، AI و تلگرام/واتس‌اپ صفحه یا CTA فعال ندارند. فایل‌های backend، migration، API و استقرار در این مرحله تغییر نکرده‌اند.
